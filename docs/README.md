# Документация проекта

Здесь находятся аналитические и редакционные документы, которые не являются частью пользовательского интерфейса сайта.

## Аудиты

- [Аудит главной страницы: фразы, влияние на клиента и возможные последствия](audits/AUDIT_INDEX_CLIENT_IMPACT.md) — каталог заявлений главной страницы, классификация формулировок, вероятное восприятие посетителя, риски и рекомендации по редактуре.

## Документы в корне репозитория

- [README.md](../README.md) — краткое описание проекта и ссылки.
- [DEVELOPMENT.md](../DEVELOPMENT.md) — устройство сайта, публикация, SEO, аналитика и технические проверки.

## Принцип размещения

Файлы, необходимые GitHub Pages для публикации статического сайта, остаются в корне репозитория. Документы, не участвующие в работе сайта, размещаются в docs/. Каталоги assets/ остаются на своих текущих путях, поскольку HTML, CSS и JavaScript используют относительные ссылки на эти ресурсы.
