## Принцип размещения

Внутри concept-v0 файлы публикации и основные ресурсы разделены по назначению: главная страница и системные файлы остаются в корне концепта, дополнительные HTML-страницы находятся в pages/, документация — в docs/, изображения — в assets/. Все локальные ссылки настроены относительно нового расположения файлов.
