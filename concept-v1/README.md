# Отдельный концепт сайта

Это самостоятельный вариант главной страницы по согласованному визуальному референсу.

## Просмотр

После публикации GitHub Pages страница будет доступна по адресу:

https://styleofmind.github.io/concept-v1/

## Важно

- Этот каталог не заменяет и не изменяет действующий сайт в корне репозитория.
- HTML и CSS концепта находятся только в папке \`concept-v1/\`; стили встроены в отдельный файл \`styles.css\`.
- Внешние файлы текущего сайта не используются. Иллюстрации и декоративные эффекты созданы средствами SVG и CSS.
- Кнопки записи ведут в существующую систему DIKIDI, ссылка на Telegram — в опубликованный канал.
- Страница помечена \`noindex,nofollow\`, пока концепт не утверждён.
- Перед использованием как основного сайта нужно проверить содержание, согласия на отзывы, правовые тексты, отображение на телефонах и доступность.
- Примеры отзывов взяты с текущей публичной страницы; перед запуском концепта нужно подтвердить согласия на повторное размещение.

## Файлы

- \`index.html\` — разметка и тексты концепта.
- \`styles.css\` — отдельное оформление и адаптивность.
