## Публикация и проверка

GitHub Pages публикует статические файлы из ветки `main`. Отдельная команда сборки не требуется: изменения HTML, CSS, JavaScript и изображений становятся доступны после публикации GitHub Pages.

Перед отправкой изменений проверьте, что:
- все локальные пути к изображениям и страницам существуют;
- в `index.html` корректны canonical, Open Graph, Twitter и JSON-LD ссылки;
- JavaScript-файлы проходят проверку синтаксиса;
- в PR не попали случайные изменения видимого текста.

### Согласие и события

`analytics.js` не запрашивает скрипты аналитических провайдеров до согласия пользователя на аналитические cookies. Выбор согласия хранится с периодом действия 180 дней. При отзыве согласия аналитика отключается; перезагрузка страницы используется для завершения уже запущенного стороннего кода. В Google Consent Mode аналитическое хранилище получает разрешение только после согласия, а рекламные разрешения остаются запрещёнными.

В коде предусмотрены события:
- `booking_click` — нажатие на ссылку записи;
- `telegram_click` — переход в Telegram;
- `analytics_ready` — инициализация аналитики после согласия.

События отправляются в Яндекс Метрику через `reachGoal` и в GA4 с явным `send_to`. Для просмотра целей `booking_click` и `telegram_click` настройте соответствующие цели в интерфейсе Яндекс Метрики.
