# Отдельные визуальные объекты

Здесь будут храниться самостоятельные иллюстрации, декоративные элементы и графические объекты, которые размещаются поверх фона или внутри секций.

Каждый объект готовится отдельно, с прозрачным фоном, если это подходит задаче. Утверждённые версии подключаются к странице независимо от фоновых изображений.
